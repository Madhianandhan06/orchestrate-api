# Third-Party API Orchestration in MERN 🚀

Learning how to connect external services (Cloudinary, Twilio, Stripe, OpenAI, Razorpay, etc.) with your Express server.

> The goal isn't to learn one API — it's to learn the integration pattern once and reuse it everywhere.

## 1. Install the provider SDK

```bash
npm install cloudinary
```

Most providers expose either an SDK (`npm install ...`) or a REST API that you call with `fetch()`.

---

## 2. Create a dedicated service/provider file

Keep third-party logic separate from routes.

```text
server/
└── services/
    └── cloudinary.js
```

Each provider gets its own service file (`twilio.js`, `stripe.js`, `openai.js`, etc.).

---

## 3. Configure provider credentials

Store secrets in `server/.env`.

```env
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

Configure the SDK once.

```js
import { v2 as cloudinary } from "cloudinary";

cloudinary.config({
  cloud_name: process.env.CLOUDINARY_CLOUD_NAME,
  api_key: process.env.CLOUDINARY_API_KEY,
  api_secret: process.env.CLOUDINARY_API_SECRET,
});

export default cloudinary;
```

Now the SDK is authenticated for future requests.

---

## 4. Build the React upload UI

Create state for the selected file.

```jsx
const [image, setImage] = useState(null);
```

Create:

* File input
* Upload button

When the user selects a file, store the first file object in state.

---

## 5. Send the file using FormData

Files are **not JSON**. Use `FormData`.

```jsx
const formData = new FormData();
formData.append("image", image);

await fetch("http://localhost:5000/upload", {
  method: "POST",
  body: formData,
});
```

`"image"` is the field name sent to the backend.

---

## 6. Receive the file with Multer

Install Multer.

```bash
npm install multer
```

Configure it.

```js
const upload = multer({ dest: "uploads/" });
```

Use middleware on the upload route.

```js
app.post("/upload", upload.single("image"), async (req, res) => {
  console.log(req.file);
});
```

`upload.single("image")` must match `formData.append("image", image)`.

---

## 7. Upload the file to the provider

Call the provider SDK with the uploaded file path.

```js
const result = await cloudinary.uploader.upload(req.file.path);
```

The SDK sends an HTTPS request to Cloudinary and returns a response object.

---

## 8. Return only the useful response

Don't send the entire provider response.

```js
res.json({
  imageUrl: result.secure_url,
  publicId: result.public_id,
});
```

Keep only the fields your frontend or database needs.

---

## 9. Render the uploaded image in React

```jsx
const data = await response.json();

setUploadedUrl(data.imageUrl);
```

```jsx
<img src={uploadedUrl} alt="Uploaded Image" />
```

The browser loads the image directly from Cloudinary's CDN.

---

## 🧠 Reusable orchestration pattern

1. Install SDK (or use `fetch()`).
2. Store credentials in `.env`.
3. Configure the provider once.
4. Receive user data/files in Express.
5. Call the provider asynchronously.
6. Read the response object.
7. Return only the required data to React or save it to MongoDB.
